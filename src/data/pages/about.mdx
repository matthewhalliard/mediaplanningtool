# About this directory

Media Planning Tool is a directory of software for planning, buying and measuring advertising. It covers what each tool does, who it is for, and what is known about its pricing, along with calculators, a glossary and guides.

## Who publishes it

The directory is published by [Halliard](https://www.halliardmedia.com/plan?utm_source=mediaplanningtool&utm_medium=referral&utm_campaign=directory&utm_content=about), which makes a media planning and buying product. Halliard is listed in the directory, appears in some comparison articles, and is linked from the calculators, glossary and resource pages. Those pages carry a note saying so.

## Corrections

If a listing is wrong or out of date, [tell Halliard](https://www.halliardmedia.com/demo?utm_source=mediaplanningtool&utm_medium=referral&utm_campaign=directory&utm_content=corrections), the publisher, and include the page and a source for the correct information.
